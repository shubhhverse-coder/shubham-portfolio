# Shubham Mandal — Personal Portfolio

A responsive, single-page developer portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a public repository named `shubham-portfolio` on GitHub.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages section.

## Before submitting
- Confirm the email and LinkedIn URLs in `index.html`.
- Add links to project repositories when they are public.
- Add genuine certificates only when you have them.
- Check the published website on both mobile and desktop.
